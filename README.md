An entry for the make.fun bounty "One Letter for Your Day". Running
`main.py` writes exactly one character -- a letter from A to Z, and
nothing else -- to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

The letter is B, for buffering: a day that kept pausing mid-sentence,
loading in small circles, and never quite arriving. The obvious pick,
Z for zero sleep, is the example the bounty itself prints, so this
entry takes the sharper letter instead.

The program validates the entry before writing it: exactly one
character, A to Z, and the output file is made world-readable so the
grader can collect it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Entries in this competition are judged in private blind rounds; a judge
model reads two letters at a time and picks the one whose word behind
it feels more vivid, funnier or more true.
